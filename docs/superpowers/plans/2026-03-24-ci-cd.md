# CI/CD Pipeline Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Docker-only CI with Rust CI + release workflow that publishes binary artifacts to GitHub Releases.

**Architecture:** Two GitHub Actions workflows — `ci.yml` (lint, test, build on push/PR) and `release.yml` (test, build, publish on tag/manual). Both use Rust 1.75 toolchain with shared cache.

**Tech Stack:** GitHub Actions, dtolnay/rust-toolchain, Swatinem/rust-cache, softprops/action-gh-release

**Spec:** `docs/superpowers/specs/2026-03-24-ci-cd-design.md`

## Task 1: Create `ci.yml`

**Files:**
- Delete: `.github/workflows/test.yml`
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Delete old workflow**

```bash
rm .github/workflows/test.yml
```

- [ ] **Step 2: Create `ci.yml`**

Create `.github/workflows/ci.yml` with this content:

```yaml
name: CI

on:
  push:
    branches: [dev, main]
  pull_request:
    branches: [main, dev]
  workflow_dispatch:

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

env:
  CARGO_TERM_COLOR: always

jobs:
  lint:
    name: Lint
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v4

      - uses: dtolnay/rust-toolchain@stable
        with:
          toolchain: "1.75.0"
          components: rustfmt, clippy

      - uses: Swatinem/rust-cache@v2
        with:
          shared-key: "isolde"

      - name: Check formatting
        run: cargo fmt --check

      - name: Run clippy
        run: cargo clippy --all-targets -- -D warnings

      - name: Install shellcheck
        run: sudo apt-get update && sudo apt-get install -y shellcheck

      - name: Lint shell scripts
        run: find core/features -name "*.sh" -type f -exec shellcheck {} +

      - name: Install jq
        run: sudo apt-get install -y jq

      - name: Validate JSON files
        run: |
          find core/features templates -name "*.json" -type f | while read -r json; do
            echo "Checking $json"
            jq empty "$json"
          done

  test:
    name: Test
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v4

      - uses: dtolnay/rust-toolchain@stable
        with:
          toolchain: "1.75.0"

      - uses: Swatinem/rust-cache@v2
        with:
          shared-key: "isolde"

      - name: Run tests
        run: cargo test

  build:
    name: Build
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v4

      - uses: dtolnay/rust-toolchain@stable
        with:
          toolchain: "1.75.0"

      - uses: Swatinem/rust-cache@v2
        with:
          shared-key: "isolde"

      - name: Build release binary
        run: cargo build --release

      - name: Upload binary
        uses: actions/upload-artifact@v4
        with:
          name: isolde-linux-x86_64
          path: target/release/isolde
          retention-days: 7
```

Expected: no error

## Task 2: Create `release.yml`

**Files:**
- Create: `.github/workflows/release.yml`

- [ ] **Step 1: Create `release.yml`**

Create `.github/workflows/release.yml` with this content:

```yaml
name: Release

on:
  push:
    tags: ['v*']
  workflow_dispatch:
    inputs:
      tag:
        description: 'Tag to release (e.g. v0.3.0)'
        required: true
        type: string

permissions:
  contents: write

env:
  CARGO_TERM_COLOR: always

jobs:
  test:
    name: Test
    runs-on: ubuntu-latest
    timeout-minutes: 15
    outputs:
      tag: ${{ steps.version.outputs.tag }}
      version: ${{ steps.version.outputs.version }}
    steps:
      - name: Determine version
        id: version
        run: |
          if [ "${{ github.event_name }}" = "workflow_dispatch" ]; then
            TAG="${{ inputs.tag }}"
          else
            TAG="${GITHUB_REF_NAME}"
          fi
          echo "tag=${TAG}" >> "$GITHUB_OUTPUT"
          echo "version=${TAG#v}" >> "$GITHUB_OUTPUT"

      - uses: actions/checkout@v4
        with:
          ref: ${{ steps.version.outputs.tag }}

      - uses: dtolnay/rust-toolchain@stable
        with:
          toolchain: "1.75.0"

      - uses: Swatinem/rust-cache@v2
        with:
          shared-key: "isolde"

      - name: Verify tag matches Cargo.toml version
        run: |
          CARGO_VERSION=$(grep '^version' Cargo.toml | head -1 | sed 's/.*"\(.*\)".*/\1/')
          VERSION="${{ steps.version.outputs.version }}"
          if [ "$VERSION" != "$CARGO_VERSION" ]; then
            echo "::error::Tag v${VERSION} does not match Cargo.toml version ${CARGO_VERSION}"
            exit 1
          fi

      - name: Run tests
        run: cargo test

  build:
    name: Build & Package
    runs-on: ubuntu-latest
    timeout-minutes: 15
    needs: test
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ needs.test.outputs.tag }}

      - uses: dtolnay/rust-toolchain@stable
        with:
          toolchain: "1.75.0"

      - uses: Swatinem/rust-cache@v2
        with:
          shared-key: "isolde"

      - name: Build release binary
        run: cargo build --release

      - name: Package artifact
        run: |
          mkdir -p dist
          cp target/release/isolde dist/
          cp -r core/features dist/
          cp -r templates dist/
          cp presets.yaml dist/
          tar czf isolde-linux-x86_64.tar.gz -C dist .
          sha256sum isolde-linux-x86_64.tar.gz > isolde-linux-x86_64.tar.gz.sha256

      - name: Upload artifact
        uses: actions/upload-artifact@v4
        with:
          name: release-artifact
          path: |
            isolde-linux-x86_64.tar.gz
            isolde-linux-x86_64.tar.gz.sha256

  release:
    name: Publish Release
    runs-on: ubuntu-latest
    timeout-minutes: 10
    needs: [test, build]
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ needs.test.outputs.tag }}

      - name: Download artifact
        uses: actions/download-artifact@v4
        with:
          name: release-artifact

      - name: Extract changelog
        id: changelog
        run: |
          VERSION="${{ needs.test.outputs.version }}"
          BODY=$(awk "/^## \[${VERSION}\]/{found=1; next} /^## \[/{found=0} found" CHANGELOG.md)
          # Use a delimiter for multiline output
          echo "body<<CHANGELOG_EOF" >> "$GITHUB_OUTPUT"
          echo "$BODY" >> "$GITHUB_OUTPUT"
          echo "CHANGELOG_EOF" >> "$GITHUB_OUTPUT"

      - name: Create GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          tag_name: ${{ needs.test.outputs.tag }}
          name: Isolde ${{ needs.test.outputs.tag }}
          body: ${{ steps.changelog.outputs.body }}
          files: |
            isolde-linux-x86_64.tar.gz
            isolde-linux-x86_64.tar.gz.sha256
          make_latest: true
```

- [ ] **Step 2: Verify YAML is valid**

Run: `python3 -c "import yaml; yaml.safe_load(open('.github/workflows/release.yml'))"`
Expected: no error
